### Comandos para executar a aplicação:
1. python -m venv .venv
2. .venv\Scripts\activate (no README.md dizia para rodar .venv\Scripts\activate.bat mas não ativou o ambiente virtual, funcionou sem o .bat)
3. pip install -r requirements-dev.txt
4. no .env, modificar a variável PROJECT_ROOT para o endereço em que o projeto está 
5. python menu.py
6. selecionar a opção 1
